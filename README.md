# App Store Reviews Downloader

Внутренний инструмент: вставляете ссылку на приложение в Apple App Store —
получаете CSV со всеми доступными отзывами за последние 2 месяца из всех
доступных регионов. Не требует знаний программирования, API Apple или
аккаунта App Store Connect.

## Что делает приложение

1. Принимает ссылку вида `https://apps.apple.com/us/app/example/id123456789`.
2. Автоматически извлекает App ID.
3. Проходит по ~135 региональным витринам (storefronts) App Store.
4. Забирает доступные отзывы за последние 2 календарных месяца.
5. Строит одну таблицу, отсортированную от новых отзывов к старым.
6. Отдаёт CSV (UTF-8 с BOM — корректно открывается в Excel).

Пользователю не нужно указывать App ID, регион, период или какие-либо
API-ключи — только ссылку.

## Как работает получение данных

Данные берутся из публичного JSON-фида отзывов Apple:

```
https://itunes.apple.com/{country}/rss/customerreviews/page={page}/id={app_id}/sortby=mostrecent/json
```

Это официальный публичный endpoint Apple (тот же, что использует сама
страница apps.apple.com), не требующий авторизации, API-ключей или
App Store Connect. Дополнительно для проверки существования приложения
используется публичный iTunes Lookup API (`https://itunes.apple.com/lookup?id=...`).

Для каждого региона приложение:

- последовательно опрашивает страницы фида (Apple отдаёт до 10 страниц
  по 50 отзывов);
- не останавливается на первой пустой странице — у этого фида
  известна особенность, когда отдельные номера страниц временно
  возвращают пустой результат, а следующие за ними — полные, поэтому
  просматривается весь доступный диапазон страниц;
- для временных сетевых ошибок и HTTP 5xx выполняет до 3 попыток с
  экспоненциальной задержкой (1с → 2с → 4с);
- при HTTP 429 учитывает заголовок `Retry-After`, если он есть;
- если после всех попыток регион недоступен — фиксирует ошибку по
  этому региону и продолжает работу с остальными (частичный отказ
  одного региона не останавливает весь процесс).

Язык отзыва в самом фиде не передаётся, поэтому определяется локально
(библиотека `langdetect`, без отправки текста во внешние сервисы). Если
определить язык не удалось — используется значение `unknown`.

Дубликаты **намеренно не удаляются** — это требование продукта.
Тексты отзывов **не переводятся** — сохраняется оригинальный язык.

## Ограничения Apple

Это важно понимать перед использованием инструмента:

- **Rolling-window, а не полный архив.** Публичный фид отзывов отдаёт
  не более ~10 страниц по 50 отзывов — то есть примерно **до 500 самых
  новых отзывов на пару "приложение + регион"**. Это ограничение
  наложено самим источником данных Apple, а не этим кодом.
- Если в каком-то регионе за последние 2 месяца оставлено больше 500
  отзывов, часть самых старых из них в это окно физически не попадёт.
  В подавляющем большинстве случаев (в том числе для нишевых
  образовательных приложений) 500 отзывов на регион за 2 месяца — это
  с большим запасом, но честности ради это ограничение не скрывается.
- Порядок `sortby=mostrecent` документирован как "от новых к старым",
  но по независимым наблюдениям он не всегда строго хронологический
  постранично. Поэтому приложение не полагается на порядок ответа API
  для остановки пагинации — оно забирает все доступные страницы и
  фильтрует/сортирует по дате уже само.
- Список регионов (storefronts) поддерживается как статический список
  внутри `app.py` (`APP_STORE_COUNTRIES`), так как отдельного публичного
  no-auth API для получения актуального списка регионов именно под
  задачу отзывов Apple не предоставляет. Список стабилен и меняется
  редко; при необходимости его можно дополнить/поправить вручную.
- Никогда не заявляется "получены все существующие отзывы" — только
  "получены все доступные через этот источник отзывы за период".

Если для вашей задачи критично гарантированно получить *абсолютно все*
отзывы без ограничения в ~500 на регион — это потребует официального
Apple App Store Connect API с ключами разработчика (Issuer ID, Key ID,
`.p8`), что прямо противоречит требованию "только ссылка, без
авторизации". Если это когда-нибудь понадобится, стоит обсудить это
отдельно, так как это другая архитектура и другой UX.

## Требования

- Python 3.9+
- Зависимости из `requirements.txt`

## Установка

```bash
git clone <ваш-репозиторий>
cd appstore-review-downloader
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск локально

```bash
streamlit run app.py
```

Откроется браузер на `http://localhost:8501`.

## Deployment в Streamlit Community Cloud

1. Создайте новый репозиторий на GitHub и загрузите туда `app.py`,
   `requirements.txt`, `README.md`.
2. Зайдите на [share.streamlit.io](https://share.streamlit.io/) и
   авторизуйтесь через GitHub.
3. Нажмите "New app", выберите ваш репозиторий и ветку.
4. В поле "Main file path" укажите `app.py`.

Секреты/дополнительные настройки не нужны — приложение не использует
API-ключей.

### Troubleshooting deployment

- **Приложение не стартует / ошибка импорта** — убедитесь, что
  `requirements.txt` загружен в тот же репозиторий и не был переименован.
- **Долгая загрузка** — сбор отзывов по ~135 регионам занимает время;
  это нормально, прогресс отображается на экране.
- **Много регионов с ошибками** — временная проблема на стороне Apple
  или сети хостинга; попробуйте запустить сбор ещё раз позже.

## Как использовать

1. Откройте приложение.
2. Вставьте ссылку на приложение из App Store в поле ввода.
3. Нажмите "Получить отзывы".
4. Дождитесь завершения (прогресс отображается на экране).
5. Просмотрите таблицу отзывов и нажмите "Скачать CSV".

## Формат результата

Файл `appstore_reviews_<APP_ID>.csv`, кодировка UTF-8 с BOM (`utf-8-sig`),
колонки:

| Колонка           | Описание                                   |
|-------------------|---------------------------------------------|
| `title`           | Оригинальный заголовок отзыва               |
| `review_text`     | Полный оригинальный текст отзыва            |
| `rating`          | Оценка от 1 до 5                            |
| `publication_date`| Дата публикации (ISO 8601, UTC)             |
| `country`         | Регион/storefront, из которого получен отзыв|
| `language`        | Определённый язык оригинального текста      |

Отзывы отсортированы по `publication_date` от новых к старым. Дубликаты
не удаляются.

## Troubleshooting

- **"Некорректная ссылка"** — проверьте, что ссылка ведёт на
  `apps.apple.com` или `itunes.apple.com` и содержит `id<цифры>`.
- **"Не удалось найти приложение"** — приложение с таким App ID не
  существует в App Store либо было снято с публикации.
- **"За последние 2 месяца отзывы не найдены"** — это не ошибка: у
  приложения действительно может не быть свежих отзывов.
- **Много регионов в списке ошибок** — раскройте блок "Регионы с
  ошибками", чтобы увидеть причину по каждому региону (timeout, HTTP
  код и т.д.); одиночные сетевые сбои — это нормально, остальные данные
  при этом сохраняются.
